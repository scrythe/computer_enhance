# Computer Enhance

My Solutions/Implementations for the Computer Enhance Homework <https://www.computerenhance.com>
Clone <https://github.com/cmuratori/computer_enhance> for input data.

In order to run the zig solutions.
Go to the zig directory, and execute the desired file

```bash
cd zig
zig build run -Dfile=listing_0037_single_register_mov
```

In order to execute the c version

Build the project and provide run argument to run it

```bash
./bash.sh run
```
